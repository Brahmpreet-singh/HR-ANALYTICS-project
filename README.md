# HR Analytics Dashboard | Power BI

## 1. Project Overview

This project is an **HR Analytics Dashboard** developed using **Microsoft Power BI**. The dashboard analyzes employee data to understand workforce trends, employee attrition, job satisfaction, salary, departments, and other HR-related factors.

## 2. Dataset

* **Total Employees:** 1,480
* **Total Columns:** 38
* **Attrition:** 238 employees
* **Active Employees:** 1,242
* **Departments:** 3
* **Job Roles:** 9
* **Age Range:** 18–60 years
* **Average Monthly Income:** 6,504.99

## 3. Tools Used

* Microsoft Power BI
* Microsoft Excel / CSV
* Data Cleaning
* Data Analysis
* Data Visualization

## 4. Key Analysis

The dashboard analyzes:

* Employee Attrition
* Department-wise workforce
* Age groups
* Gender distribution
* Job Roles
* Job Satisfaction
* Environment Satisfaction
* Overtime
* Monthly Income
* Education
* Business Travel
* Years at Company
* Performance Rating
* Work-Life Balance

## 5. Key Findings

* **238 employees** have left the organization.
* **1,242 employees** are currently active.
* Research & Development has **967 employees**.
* Sales has **450 employees**.
* Human Resources has **63 employees**.
* **418 employees** work overtime.
* **1,062 employees** do not work overtime.
* The dataset contains **889 male** and **591 female** employees.

## 6. Dashboard Features

* Interactive KPI cards
* Attrition analysis
* Department and job-role analysis
* Employee demographic analysis
* Salary analysis
* Interactive filters and slicers
* Charts and visualizations
